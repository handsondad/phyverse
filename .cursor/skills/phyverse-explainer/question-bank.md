# 物理奇遇记 · 题库

每一题都是一篇「小念 × 爸爸」文章的种子。标 ⭐ 的是第一批，已经写成文章（以 `npm run story:todo` 为准，标题以 curriculum 的 `question` 为准）；没标 ⭐ 的是候选，写之前照 sources.md 重新查证。新题按同样的列加进对应主题的表里。选题标准：

- **从生活出发**：小念在家里、路上、操场、天上真的会碰到的一幕。
- **破一个误区**：每题至少瞄准一个有研究记录的常见误区（MOSART、FCI 等误区研究，见文末）。
- **对得上课标**：入门 ≈ 小学高年级 / 初二，进阶 ≈ 初三，综合 ≈ 高中（必修、选择性必修）。
- **能动手**：每题配一张能拖滑块的互动图（已有的写 sims.ts 里的名字，新的写「新：…」）。PhET 只在自己做不出同等效果时才嵌入，嵌入前到 phet.colorado.edu 核实该实验是 HTML5 版、许可仍是 CC BY-NC。
- **查证去处**：写文章时数字和说法要去这些地方核实，写进文章的「参考来源」。物理所问答、《1分钟物理》只当选题灵感和核对思路，**不抄原文**；OpenStax 新许可禁止喂给 AI，**不读不用**。

⭐ = 建议首批（每类先做 6–8 篇）；🔭 = 这题顺便做 3D 实验台那节课的文章。
