# 配图和互动图

配图写在爸爸那一轮的 `figure` 里，画在他的气泡中。类型和画法在 `src/learning/figures.ts`；互动图登记在 `src/learning/sims.ts`，每个主题的互动图写在 `src/learning/simlib/<主题>.ts`（`motion`、`pressure`、`energy`、`heat`、`sound`、`light`、`circuit`、`cosmos`），共用的画图工具（`txt`、`arrow`、`poly`、`G`、颜色）在 `simlib/kit.ts`。

## 规矩（检查器会拦）

- 每篇 1–2 张能拖滑块的互动图（`sim`）。
- 没有动画的文章至少 3 轮配图（正常文章都有动画，这条是兜底）。
- `caption` ≤70 字，说清「拖哪个、看什么」，不重复爸爸的原话。
- `bars` 画 2–6 根柱子，名字 ≤6 字、柱尾的数 ≤12 字、数值都大于 0。
- `scale` 画 3–5 档，顶栏 `axis` ≤14 字，每档标签 ≤7 字、说明 ≤9 字。
- `/images/photos/` 下的照片要写 `credit` 和 https 的 `href`（见 sources.md）。

## 选哪种图

| kind | 用来讲 | 关键字段 |
|---|---|---|
| `sim` | 孩子拖一个量、看另一个量怎么变：刹车快慢和前冲、出手角度和射程、排水量和浮力 | `sim`、`caption` |
| `bars` | 几样东西比大小：几种材料里的声速、几颗星的距离、几种发电方式 | `unit`、`bars` |
| `scale` | 3–5 档区间横着排：电磁波谱、温度台阶 | `axis`、`stops` |
| `image` | 真照片（NASA、Wikimedia）或 3D 课件封面 | `src`、`alt`、`credit`、`href` |

一张图只帮爸爸说清这一句。互动图放在最关键的那一轮（通常是讲「怎么发生」或「误区」的那轮）。

## 写一个新的互动图

题库里写着「新：…」的题要新写一个 sim。在对应主题的 `simlib/<主题>.ts` 里照现有的写一个 `SimDef` 并导出，再在 `sims.ts` 里引进来、加进 `SIMS`：

- **画面只由滑块和时间决定**：`draw(state, t)` 返回 560×320 画布里的 SVG 片段，`readout(state)` 返回一句读数（「刹车用了 0.5 秒：上身往前冲了 30 厘米」）。不要在里面存状态。
- **物理要真**：用真实公式算（`G = 9.8`），画面上需要夸张的（比如色散角度放大 3 倍）在注释里写清楚，读数里写真值。
- **滑块 1–3 个**：每个都是孩子能理解的量（「刹车快慢」而不是「减速度」）；分档的用 `labels`。范围两头的画面也要合理。
- **文字**：SVG 文字走 `text()` 帮手函数（带白描边，深色底上用 `plain: true`）；文字别出画布、别互相压。
- **会动的**设 `animated: true` 和 `still`（减少动态效果时停在哪一秒）；页面只在看得见时播。
- **测试**：`tests/sims.test.ts` 会把每个 sim 的滑块拖遍最小 / 中间 / 最大的组合，查有没有 `NaN`、空读数；新 sim 自动进测试。
- **看一眼**：`npm run story:sims -- <sim...>` 把滑块两头、几个时刻的画面排成联系表（`.story-preview/sims-*.png`），逐格看字有没有出框、画面对不对。
- 写完更新本文件的「现有的互动图」表。

## 每种图的写法

**`sim`**：`{ kind: 'sim', sim: 'inertia', caption: '把刹车拖得更急：车停得越快，人往前冲得越远。' }`。页面自动加「👆 拖一拖滑块 · 」前缀。

**`bars`**：`{ kind: 'bars', unit: '米/秒', caption: '…', bars: [{ label: '空气', value: 340 }, { label: '水', value: 1500 }, { label: '钢铁', value: 5200, hot: true }] }`。柱子按最大值等比画，`hot` 那根是橙色；柱尾不写 `text` 就显示「数值 单位」。数值要有来源。

**`scale`**：`{ kind: 'scale', axis: '波长越来越短 →', stops: [{ label: '无线电波', note: '收音机', color: '#…' }, …], caption: '…' }`。色块深浅自动切换白字 / 深棕字，`hot` 那一档加橙色外圈。

**`image`**：先打开图片看清画面再写图注；课件封面从 `../assets` 引 `lessonAsset('covers/xxx.webp')`（从 `../catalog` 引会循环引用）。

## 加一种新图

1. 在 `figures.ts` 的 `Figure` 里加一种 kind，`renderFigure` 里画出完整的静态 SVG（没有脚本也能看，文字转义）。
2. 在 `rules.ts` 的 `figureProblems` 补检查，在 `tests/stories.test.ts` 补测试。
3. 样式写进 `learning.css` 的 `.fig-<kind>`，颜色用 `--cv-*` 变量。
4. 更新本文件。
