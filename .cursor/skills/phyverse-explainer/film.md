# 右栏的讲解动画

动画写在 `Story.film` 里，放在文章右栏（宽屏吸附在右边，窄屏在对话上方），带小念和爸爸的语音讲解。引擎在 `src/learning/film/`（`engine.ts` 时间线、`stage.ts` 画面、`player.ts` 播放器、`narration.ts` 配音版时间线）。画布固定 1200×900，坐标都是 `[x, y]`，y 往下增大。每个元素只由时间 t 决定，所以能暂停、拖动、从任意一帧看。

**配音会把戏拉长**：有声音时，一场戏（或配同一轮的几场戏）要等这一轮的两句读完，整场按比例放慢，`from`/`to`、`travel`、`over`、`rise`、`tint`、`slide`、`amount`、镜头 `t` 一起拉长；`flow`、`pulse`、`wave`、抖动、摆动、打字、画箭头保持原速。所以戏照原速写，元素先后顺序对上爸爸说话的顺序就行。没配到戏的轮次（通常是最后的总结）接在前一场后面读。

**每一场演爸爸这一轮讲的东西**：物理最适合演——刹车时人往前冲、球画出弧线、声波一圈圈传出去、光线拐弯、摆锤来回荡、电荷沿导线流。点对话里的「🎬 看动画」，就从这一轮的第一场开始播。

## 规矩（检查器会拦）

- 一轮问答配一到三场戏：至少 4 场；第一场配第 1 轮（`turn: 0`）；`turn` 按对话顺序只能不变或变大；最多跳过 1 轮（总结轮通常不配戏）；同一轮不超过 3 场。
- 每场 4–14 秒，全片 30–150 秒。
- 每场至少 2 个元素，任何时刻同屏不超过 8 个，用 `to` 把旧元素收走。
- `from` ≤ 时长 − 0.8；`to` ≥ `from` + 0.5，且不超过时长。
- 镜头 `zoom` 1–2.6。
- 文字长度：场次标题 ≤12、`label` ≤12、`text` ≤14、`arrow` ≤10、`shape` ≤7、`meter` / `count` 标签 ≤8、`myth` 每句 ≤18。
- `ray` 至少 2 个点；`swing` 摆角 0–80°；`toss` 的地面要在出手点下方。
- 左上角留给场次标题，别把元素放在 y < 140 的左上角。

## 画法

1. **逐步长出来**：按爸爸台词的先后一个个加元素，间隔 0.6–1.5 秒。说到哪个，哪个才出现。
2. **比方要画出来**：爸爸说「像拔河」，就画两边拉的箭头；说「像排队传话」，就用一排 `atom` 依次 `pulse`。
3. **误区要翻过来**：爸爸说破误区的那一轮放 `myth` 卡，先划掉错的，再亮出对的。
4. **字要少**：屏幕上只放关键词，完整的话交给旁边的对话。
5. **结尾一句**：每场最后用一行 `text` 点题（≤14 字），放在下方 y≈760–830。
6. **后写的盖在上面**：`cues` 的顺序就是画的顺序；标签、`text` 写在最后。
7. **误区卡占底部**：有 `myth` 的那场，y > 720 的地方别再放东西（点题的 `text` 往上挪到 y≈700，或不要）。
8. **会动的东西真的动**：`sprite`、`atom` 沿 `path` 走；`shape` 用 `slide` 平移；抛出去的用 `toss`，摆的用 `swing`；别用「先收走、再在新位置放一个」冒充移动。有多个点的 `sprite` 在 `from` 之前是看不见的：要它先站着、过一会儿再走，就放一个只有起点、`to: X` 的静止副本，走的那个写 `from: X`。
9. **物理要对**：`toss` 的轨迹是真抛物线（`velocity` 像素/秒、`gravity` 像素/秒²）；力的箭头长短要和大小对得上；光线的入射角和折射角方向别画反。
10. **数字只用爸爸说过的**：`count`、`meter` 的标签和 `text` 里出现的数，爸爸这一轮里都要说过；只想表现「多 / 少」就用 `meter`。

## 元素一览（`types.ts` 的 `Cue`）

| kind | 用来 | 主要字段 |
|---|---|---|
| `text` | 一行大字点题 | `at`、`text`、`size: 's'/'m'/'l'` |
| `formula` | 公式逐字打出 | `at`、`text` |
| `label` | 带引线的标签 | `at`（指向点）、`pos`（文字位置）、`text` |
| `atom` | 带字的小球：分子、电子、电荷、小车；多点 `path` 时沿路线走 | `path`、`symbol`、`color`、`charge`、`travel`、`motion` |
| `bond` | 两点之间的一根杆 / 绳 / 导线 | `a`、`b` |
| `shape` | 车厢、木块、地面、电池……可写字、变色，`slide` 平移 | `shape`、`at`、`size`、`color`、`text`、`tint`、`motion`、`slide` |
| `vessel` | 烧杯 / 瓶子，液面涨落变色（浮力、压强、沸腾） | `vessel`、`at`、`size`、`liquid`、`level`、`rise`、`tint`、`label` |
| `particles` | 一群分子乱飞、原地抖、气泡上升，个数可增减 | `box`、`count`、`color`、`motion`、`amount` |
| `sprite` | 一个 emoji 弹出或沿路线走（🚌 🧍 ⚽ 🌙） | `icon`、`path`、`travel` |
| `arrow` | 一笔画出的箭头（力、速度、光线方向） | `path`、`text` |
| `flow` | 一串小点沿路线流（电流、热、气流、水流） | `path`、`count`、`speed`、`loop` |
| `pulse` | 一圈圈波纹（声源、撞击、放电） | `at`、`radius` |
| `wave` | 从 a 往 b 传过去的一列波（声波、绳波、水波） | `a`、`b`、`amplitude`、`wavelength`、`speed` |
| `ray` | 一束光沿路线画过去，拐点就是反射、折射 | `path`、`color`、`draw` |
| `swing` | 挂着来回摆的小球（单摆、秋千、保龄球摆锤） | `pivot`、`length`、`angle`、`period`、`damping`、`icon` |
| `toss` | 抛出去的东西：真抛物线，落地停下，留虚线轨迹 | `at`、`velocity`、`gravity`、`ground`、`icon` |
| `meter` | 进度条涨落（速度、温度、压强） | `at`、`label`、`start`、`end`、`over` |
| `count` | 数字从 start 数到 end | `at`、`label`、`start`、`end`、`unit` |
| `myth` | 误区卡：划掉错的、换成对的 | `wrong`、`right` |

所有元素都有 `from`（出现秒数）和可选的 `to`（消失秒数）。

## 常用配方

- **惯性**：`shape` 车厢 `slide` 停下，`sprite` 乘客沿 `path` 继续往前走一小段；`arrow` 标出「脚被拉停」。
- **力和运动**：`shape` 木块 + 力的 `arrow`（长短代表大小）+ `meter` 速度涨落。
- **抛体**：几个 `toss` 不同角度从同一点出手，比落点。
- **声音**：`pulse` 声源 + `wave` 传向耳朵 `sprite`；`count` 数秒。
- **光**：`ray` 从光源经过拐点到眼睛；水面用 `shape` 浅蓝矩形。
- **电路**：`bond` 画导线，`flow` 沿闭合回路 `loop` 流动，灯用 `shape` + `tint` 变亮。
- **能量互换**：`swing` 或 `sprite` 沿轨道走 + 两个 `meter`（高度、速度）一涨一落。

写完先跑 `npm run story:frames -- <slug>`，看 `.story-preview/<slug>-frames.png`：每场一行三帧，元素不重叠、字不出框、该出现的都出现了。再在浏览器里开着声音从头听一遍。

## 一轮配几场戏

- 大多数轮一场就够。爸爸一句话里讲了两件事（「先……再……」），就拆成两场，`turn` 写同一个数，按顺序排。
- 同一轮最多 3 场；点「🎬 看动画」从这一轮的第一场开始，播完自动接下一场。
- 动画只给「看」，自己动手的交给互动图和「🔭 3D 实验台」；一场讲清一件事，台词留在文章里。
