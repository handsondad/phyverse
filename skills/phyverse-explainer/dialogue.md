# 写问答

文章写在 `src/learning/stories/<slug>.ts`，导出一个 `Story`（类型见同目录 `types.ts`），登记在 `stories/index.ts`。`npm run story:new -- <slug>` 会把这两步做好。写完跑 `npm run story:check -- <slug>`，再跑 `npm run voice -- <slug>` 配音。

**对话会被读出来**：小念和爸爸的每一句都是配音稿，写成嘴上说得出的话。公式放进 `eq`（不读），句子里说名字和中文单位：「每秒 340 米」「大约 10 牛」。非写符号不可（`m/s²`、`μA`、`Hz`），`src/learning/voice.ts` 的 `speakable()` 会把常见单位和物理量念成中文；`story:check` 对念不顺的英文字母串会给 ⚠️，缺的念法补进 `voice.ts`。

## 字段

| 字段 | 写什么 |
|---|---|
| `slug` | 和 `curriculum.ts` 里的课一致 |
| `title` | 小念口吻的问题，必须带「？」：「公交车一刹车，我为什么会往前冲？」 |
| `trigger` | 小念刚遇到的那件事，一句话、具体到场景：「早上坐公交车上学，司机一脚急刹，小念差点扑到前面叔叔身上……」 |
| `dialogue` | 5–8 轮 `{ nian, dad, eq?, figure?, show? }` |
| `tip` | 给大人：安全须知、数字的口径、和教材写法的差别、可以在家一起做的小实验；至少 20 字 |
| `sources` | 参考来源，至少 2 条，见 sources.md |
| `film` | 讲解动画，每篇都要有，见 film.md |

每轮里：
- `eq`：这一轮的公式或算式，单独排一行（`F = ma`、`p = F / S`、`340 m/s × 3 s ≈ 1 km`）。入门的题尽量不放公式，进阶最多一两条，综合可以多一些。
- `figure`：爸爸边说边指的一张图，见 figures.md。
- `show`：`{ kind: 'lab', step, label }` 记下这一轮对应 3D 实验第 `step` 段（从 0 数）；或 `{ kind: 'steps', frames }` 一排 2–4 格的小图解（emoji + ≤8 字）。

## 检查器会拦的

- 5–8 轮；标题带「？」；`trigger` 一句话（≥8 字）。
- 除最后一轮外，小念每句都带「？」。
- 从第 2 轮起，小念的问题要用上爸爸上一句里的一个有意义的两字词（「惯性」「摩擦」「浮力」；「什么」「这个」不算）。检查器取相邻两个汉字，其中一个是「的了吗是我你这那就也都还在有和么什怎为个一不没会要说想看能可以得很太好真再」这类虚字就不算；最稳的是让小念原样复述爸爸刚说的一个名词：「摩擦力还能帮我们往前走？」。
- 最后一轮小念以「我懂了」或「我明白了」开头。
- 爸爸每句 20–180 字；`tip` 至少 20 字；`sources` 至少 2 条。

## 写好的标准（检查器管不到的）

**小念**：孩子的口气，短句，带情绪：「哇，我差点撞到前面的叔叔！」。追问顺着爸爸刚说的新词往下挖，不跳题：爸爸说了「惯性」，小念就问「惯性是一种力吗？」。小念可以先说出那个常见的错误想法（「是不是有一股力把我往前推？」），让爸爸接着说破——这是破误区最自然的写法。

**爸爸**：
- 第一句就给答案，再解释。
- 一个比方只讲一件事，用孩子见过的东西：滑滑梯、拔河、排队传话、跷跷板、一排多米诺骨牌、挤公交。比方有漏洞就说一句「别全信这个比方」。
- 比方说完说真名，只说一次：「……这就叫惯性。」后面就直接用。
- 数字要真实、可查（写进 `sources`）；图里和动画里出现的数字只能是爸爸说过的。不确定就直说「科学家还在研究」或「大约」。
- 误区点名说破：「很多人以为……，其实……」，再给一个孩子能自己验证的证据（一个小实验、一个日常现象）。
- 不堆术语：「参考系」「合外力」这类词，入门题不说；进阶、综合题要用就先打比方。
- 学段对齐：入门题讲现象和定性的道理；进阶题可以讲简单的比例和计算；综合题可以讲公式，但先讲道理再给公式。

**追问链的常见顺序**（不必每次全用）：
1. 现象是怎么回事（是什么）
2. 一步步怎么发生（力、能量、分子、光线在干什么）
3. 为什么非得这样，不这样会怎样
4. 常见误区或特例
5. 生活里能用来做什么 / 我能做什么
6. 小念总结，爸爸肯定并给一个好习惯或一个能回家试的小实验

## 例子

```ts
{
  nian: '爸爸，车一刹车我就往前冲，是不是有一股力把我往前推？',
  dad: '没有谁推你哦。车停下时，你的脚被车厢地板拉着一起停了，可你的上身还想照原来的样子往前走，就扑出去了。东西总想保持原来的样子，这就叫惯性。',
  figure: { kind: 'sim', sim: 'inertia', caption: '…' },
},
{
  nian: '惯性是一种力吗？车开得越快，惯性越大吗？',
  dad: '很多人这么以为，其实惯性不是力，它是东西自己的「脾气」……',
},
```

第 2 轮的「惯性」接的是爸爸上一句的原话，这就是追问链；第 1 轮小念说出了误区，爸爸当场说破。

## 草稿怎么改

`story:new` 预填的是自动装配的问答（3D 实验课用课件的一问一答，生活问题用 `curriculum.ts` 里的 hook 和 takeaway），口气不对。改写时：
- 删掉「教材」「本实验」「实验台上」「p.89」这类老师口吻，换成小念生活里的场景；
- 并掉重复的轮次，控制在 5–8 轮；
- 3D 实验课保留 `show.lab` 的段号（和课件对得上），删掉用不上的；
- 把注释掉的 `// figure:` 换成真的图，把 `sources` 填上。
